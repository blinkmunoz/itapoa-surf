# Surf Itapoá

Uma página para acompanhar as condições do mar, o clima e a previsão das
próximas horas em Itapoá, Santa Catarina. O layout funciona em computadores e
celulares e usa uma ilustração original inspirada no litoral.

## Executar localmente

```sh
npm install
npm run dev
```

Para validar a versão de produção:

```sh
npm run build
npm run preview
```

## Dados

As condições do tempo e do mar são consultadas no
[Open-Meteo](https://open-meteo.com/) para as coordenadas da região de Itapoá.
Os valores são estimativas e podem variar entre pontos diferentes da praia.
